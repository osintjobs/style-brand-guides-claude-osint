# Meridian Style Kit

Sample style guide, brand voice document, and skill description for producing consistently branded reports and LinkedIn content with Claude.

This accompanies the [OSINT Jobs Newsletter](https://osintnewsletter.osint-jobs.com), which walks through how to set this up for your own brand.

## What's in this repo
meridian_style_guide.pdf — visual identity, mood, and format specs for a report and a matching LinkedIn card
meridian_brand_voice.pdf — tone, vocabulary, and structure rules, with a before and after example
skill_description.md — sample prompt for turning both documents into a reusable Claude skill

"Meridian Risk Group" is a fictional brand, used for illustration only. Swap it for your own colours, typography, and voice, and use these as a template.

## Why two documents

A style guide governs how output looks. A brand voice document governs how it reads. Give Claude both, and it produces reports and social content that are consistent in appearance and in tone, without you re-explaining either each time.
